# CopyPasteBin — Linux package

**English** | [Polski](README.pl.md)

Local clipboard protection and a handy text editor for GNOME Shell 50 on Wayland.
Check the application version in the About window.

the application's interface language (English, Polish, or system default).
The absence of a warning does not guarantee that text is safe.
