# CopyPasteBin — pakiet Linux

**Polski** | [English](README.md)

Lokalna ochrona schowka i podręczny edytor tekstu dla GNOME Shell 50 na Waylandzie.
Wersję aplikacji sprawdzisz w oknie „O programie”.

- [Instalacja, aktualizacja, odinstalowanie i diagnostyka](INSTALL.pl.md)
- [Bezpieczeństwo i ograniczenia](SECURITY.pl.md)
- [Licencja](LICENSE) i [informacje o składnikach](NOTICE)

Pakiet zawiera oba języki dokumentacji i jeden wspólny instalator.
Komunikaty skryptów instalacyjnych i diagnostycznych są po polsku;
nie zmienia to języka interfejsu programu (polski, angielski lub systemowy).
Brak ostrzeżenia nie gwarantuje bezpieczeństwa tekstu.
