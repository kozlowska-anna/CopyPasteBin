Why use it · Privacy-focused Clipboard Manager

A manager, but not a traditional clipboard archive.

Traditional clipboard managers focus mainly on storing, searching, and reusing copies. CopyPasteBin also provides a short history, but prioritizes spotting risk, preparing text, and protecting you from an unfortunate click on “Paste”.

Notice risk earlierA warning appears when text resembles a supported kind of sensitive information.
Keep the decisionThe app does not paste text or change the clipboard automatically by default.
Keep data on your deviceDetection and redaction run locally without uploading clipboard content.
Prepare safer textThe editor helps remove or anonymize selected values before use.

Example uses

When might CopyPasteBin help?

  • When writing a message: check whether copied text accidentally contains personal, contact, or financial information.
  • When working with code or a terminal: notice tokens, keys, and connection strings before pasting them into a conversation, issue, or documentation.
  • When using an AI tool: review copied text from a document, code, log, or command and redact sensitive data locally before pasting.
  • When sharing an image: manually cover selected areas of a photo or screenshot and save a new PNG copy.

Core features

Practical help for everyday copying and pasting.

01

Handy text editor

Open copied content, make manual changes, or redact detected fragments. The clipboard changes only after your confirmation.

02

Image redaction

Open a local PNG or JPEG, cover selected areas with rectangles, and save a new PNG. The original file remains unchanged.

03

Rules and exact exceptions

Custom markers stay local. Exceptions are limited to one exact low- or medium-risk detection.

04

15-item clipboard history

The history contains up to 15 recently copied text items and remains only in current-session RAM. Locking the screen, logging out, or disabling the extension clears it.

05

Four risk levels

Rules distinguish low, medium, high, and critical risk, with categories for contact details, financial data, tokens, private keys, and more.

06

Safe Paste

Use Super+Shift+V to check the text currently in the clipboard. If CopyPasteBin detects a risk, it opens the editor with a redaction suggestion. It will not paste or change anything without confirmation.

07

Pause and optional clearing

Pause durations remain visible while protection is paused, with Resume close at hand. Optional clipboard clearing stays off by default.

What it can recognize

  • email addresses, phone numbers, PESEL, IBAN, and payment cards;
  • service keys, tokens, JWTs, and database connection strings;
  • private keys, recovery keys, and valid BIP-39 phrases;
  • other heuristics depending on the filters you enable.

What it retains

  • a technical event history without clipboard content;
  • up to 15 text items in current-session RAM;
  • local settings, custom rules, and exact exceptions;
  • no telemetry, account, or cloud synchronization.

What you control

  • individual detection category filters;
  • a 30-minute, one-hour, or indefinite pause;
  • clearing after 1, 5, or 15 minutes—or keeping it off;
  • the system language, Polish, or English;
  • the local input image and destination for its redacted copy.

Privacy and security

Local, with no account or cloud.

Detection and redaction run on your computer. CopyPasteBin requires no account or connection to an AI service and does not save clipboard content in persistent history.

No telemetry or trackers

The app and this website do not send usage analytics.

Explicit limits

No warning does not mean a text is safe. Rules can miss something or raise a false positive.

No persistent content history

Up to 15 recent text items remain only in current-session RAM.

What the app cannot guarantee

CopyPasteBin helps you notice potential risk, but it is not an isolated vault.

  • It cannot protect against root or another process running as the same user.
  • It cannot control external clipboard managers, screen observation, or the destination app.
  • It cannot guarantee secure erasure from RAM, swap, or process dumps.
  • It cannot prove that no detection means no sensitive data.

System requirements

Required environment.

  • Linux with GNOME Shell 50
  • a Wayland session
  • Python 3.11 or newer with venv
  • gjs, GTK 4, GdkPixbuf, GioUnix, and gnome-extensions
  • sha256sum to verify the downloaded archive

Example of a compatible Linux distribution:

  • Ubuntu 26.04 LTS (GNOME 50, Wayland)

Currently unsupported: KDE Plasma, Cinnamon, Xfce, and X11 sessions.

Compatibility depends on the desktop environment and its version, not just the Linux distribution.

Release · 1.1

Two installers from the same source.

Choose one installation method:

  • DEB package — a system installation managed by APT.
  • tar.gz archive — a user-local installation without sudo.
↓ Download DEB↓ Download tar.gzDownload SHA256SUMS

After downloading an installer and the checksum file, verify the package in the same directory:

sha256sum --check --ignore-missing SHA256SUMS

The 1.1 tar.gz includes English and Polish documentation. Start with README.md and INSTALL.md; use the language links to switch to Polish. Both site languages use the same archive.

Both installation variants were checked in the target GNOME/Wayland environment.

Updating the DEB package currently requires downloading the new version and installing it through APT.

Do not install both variants at the same time.
